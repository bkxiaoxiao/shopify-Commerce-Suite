# Commerce Suite 界面原型

依据公司自用 Shopify 综合运营应用开发方案实现的可交互 UI，包含运营总览、运费管理、搭配销售、发票与单据、补货提醒、效果分析、设置与集成，以及顾客端预览。

这是界面原型，所有指标、客户、税号和商品信息均为演示数据；不会写入 Shopify、发送邮件或执行付款。配置使用当前浏览器的 localStorage，按英国和欧洲店铺分别保存。单据下载为 HTML，报表为 CSV。

## 查看

打开 `outputs/CommerceSuite交互原型.html` 可离线体验，无需安装依赖。

模块化源码位于 `ui/`。需要开发预览时，在工作区运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory ui
```

然后访问 http://127.0.0.1:4173/ 。

## 主要交互

- 切换英国和欧洲店铺，金额分别使用 GBP 和 EUR。
- 搜索、新建、复制和启停运费规则，输入邮编、重量及订单额模拟报价。
- 创建商品搭配、调整组合折扣，预览顾客端加购和优惠撤销。
- 筛选与预览单据，创建报价，保存自动化设置，导出 HTML 单据。
- 模拟补货和通知队列，查看邮件与订阅名单。顾客端的缺货邮箱订阅会同步到后台名单。
- 使用顶部搜索或 Command/Ctrl K 快速导航。

## 结构

- `app.js`：应用外壳、路由、总览、分析和设置。
- `styles.css`：共用布局、组件和响应式样式。
- `modules/`：四个业务模块及顾客端体验。
- `assets/`：本地 SVG 商品示意图和图标，无外部图片依赖。
- `screenshots/`：界面验证截图。

`work/package_ui.py` 将模块化源码打包为包含样式、脚本和图片的单文件离线原型。
